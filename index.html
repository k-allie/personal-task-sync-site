Keep the list structure.

Google lists are paired with matching lists in Reminders. Tasks stay connected through their identifiers, so edits return to the correct list. New reminders in a paired list can create tasks in its Google counterpart.

Change either copy.

Titles, notes, due dates, and completion can sync both ways. The utility checks Google periodically and reacts to Reminders changes. Confirmed deletions can propagate when enabled.

Runs on your Mac.

The local utility performs synchronization while the Mac is awake, online, and signed in. It requires Google authorization and macOS Reminders permission. This public website provides information; it does not run the sync or receive task data.

Know what is shared.

Task pairings, authorization tokens, recovery records, and logs are stored locally. Changes pass between Google Tasks and your configured Reminders store. Recurrence, attachments, alerts, and subtask relationships are not fully transferred.

Google authorization

Why task access is requested

Personal Task Sync requests permission to view, create, edit, and delete Google Tasks so it can synchronize your own records. It uses Google's OAuth sign-in screen and does not ask for or store your Google password.

The requested scope is https://www.googleapis.com/auth/tasks. This permission applies to task data in the authorized Google account. The utility uses it for the synchronization described here.

Read the Privacy Policy and Terms of Service. For questions, use the developer support email shown on the application's Google authorization screen.
