Personal Task Sync

Personal Task Sync is a personal utility that runs on my Mac to synchronize Google Tasks with Apple Reminders. It is for my own use.

This website provides application information, a privacy policy, and terms for the Google authorization process.

What it does

The utility pairs Google task lists with Apple Reminders lists and synchronizes task titles, notes, due dates, and completion status. Confirmed deletions can also sync when enabled. Some features, including recurrence, attachments, alerts, and subtask relationships, are not fully transferred.

Google account access

The utility requests permission to view, create, edit, and delete Google Tasks using the scope https://www.googleapis.com/auth/tasks. This access is used to synchronize tasks with Apple Reminders.

Authorization uses Google's OAuth sign-in screen. The utility does not ask for or store a Google password.

Where data is handled

Synchronization runs locally on my Mac and requires macOS Reminders permission. Authorization tokens, sync records, recovery records, and logs are stored locally. Task data passes between Google Tasks and the configured Reminders store; this website does not receive it.

Contact

For questions, use the developer support email displayed on the application's Google authorization screen.
