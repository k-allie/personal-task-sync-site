Privacy Policy

Effective October 19, 2026

Personal Task Sync is a utility operated by its account owner on a Mac to synchronize Google Tasks with Apple Reminders.

Information accessed and purpose

The utility accesses task lists and identifiers, task titles, notes, due dates, completion status, modification timestamps, and deletion indicators. It uses these records to create corresponding reminders or tasks, transfer edits, reconcile conflicts, and propagate confirmed deletions when enabled. It accesses the Mac's Reminders database through EventKit with macOS permission.

Google authorization

Google authorization uses OAuth. The utility stores access and refresh tokens locally on the Mac to support ongoing synchronization. It does not collect or store the Google account password.

Local storage and retention

Task identifiers and shared task fields are stored in local sync state. Recovery records can contain task snapshots from conflicts and deletions. Logs can contain task titles and operational errors. Authorization files, state, recovery records, and logs remain in the local project folder until the owner deletes them. Operational logs rotate; recovery history is retained until the owner removes or archives it.

Data transfers and sharing

The utility transfers task data between Google Tasks and the configured Apple Reminders store to perform the synchronization requested by the account owner. If that Reminders store belongs to a cloud account, its provider may synchronize the records under that account's settings and policies.

The utility does not upload task data or authorization tokens to this website or an application-operated server. It does not sell task data, use it for advertising, or send it to an AI model for training or inference.

Google API data use

Personal Task Sync's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google API data is used only to provide the synchronization function described on this website.

Your control and deletion choices

You can stop synchronization by disabling the local login service, revoke Google access in your Google Account settings, and revoke Reminders permission in macOS Privacy & Security settings.

To remove locally retained authorization and sync records, stop the service and delete the token, state, recovery, backup, and log files from the project folder. Deleting local records does not itself delete existing tasks in either app. Disable the service before removing sync state, since running without that state can cause duplicate imports.

This public website

This informational website is hosted by GitHub Pages. It has no task input forms, account sign-in, app analytics, advertising, or third-party scripts. GitHub may process visitor information when serving the site under the GitHub General Privacy Statement. Task data and authorization tokens are not sent to this website by the utility.

Contact

For questions about the utility's data practices, use the developer support email displayed on the application's Google authorization screen.
